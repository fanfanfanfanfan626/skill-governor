# Support

Start with the [README](README.md), [AI installation contract](AI_INSTALL.md), [worked examples](EXAMPLES.md), and [compatibility evidence](COMPATIBILITY.md).

- File a **bug report** for a reproducible CLI, audit, state, rollback, packaging, or instruction-contract failure.
- File a **feature request** for a concrete skill-governance gap that is not covered by the current workflow.
- Use a regular Issue for non-sensitive documentation corrections and host-compatibility questions.

Include the release or commit, host and version, Python version if scripts are involved, exact sanitized command or request, expected result, and actual result. Never publish credentials, absolute personal paths, private skill inventories, project associations, policies, evidence records, or backups.

Security-sensitive reports belong in the private channel described in [SECURITY.md](SECURITY.md).
