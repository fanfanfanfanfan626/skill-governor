Govern AI skills without creating skill sprawl.

Skill Governor helps an AI assistant audit its real skill library, choose the smallest sufficient workflow, track evidence and source drift, and keep host integration reversible.

Download v1.0.0中文说明

Choose less

Select the smallest sufficient skill set—including no extra skill for ordinary work.

Keep states honest

Separate discovery, source review, tool readiness, execution, verification and acceptance.

Stay reversible

Keep private state outside packages and journal authorized host-rule changes for rollback.

Install the package, not the repository root

Copy the complete skills/skill-governor directory into a verified skill root. The entry point is skills/skill-governor/SKILL.md.

Use $skill-governor to audit my skill library and propose the smallest sufficient routing policy. Keep private paths and evidence local.

Built for real governance work

Use it when skills overlap, live in multiple roots, move between devices, or need evidence-based acquisition and retirement decisions. It is intentionally not an always-on wrapper for every task.
